SUGGESTED THREAT RULES
- SCAN_HOST => informational, +5.
- LOGIN_FAILED => low, +10.
- SENSITIVE_FILE_OPENED (decoy) => high, +35, immediate alert.
- HONEYTOKEN_VIEWED => high, +40, immediate alert.
- FAKE_CREDENTIAL_USED => critical, +50, immediate alert.
- LATERAL_MOVE_ATTEMPT => high, +25.
Score = min(100, sum of scores for events in active session). Avoid scoring double counts from re-render. Show evidence per alert and explain why it fired. A normal browse is not automatically an attack.
